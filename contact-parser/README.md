# Парсер контактов: dou.ua + LinkedIn → Google Sheets

Берёт список ссылок, собирает базовые контакты людей и компаний и складывает их в Google Таблицу,
на листы `People` и `Companies`. Дубли не добавляются: ключ — ссылка на профиль или страницу.

| Лист        | Колонки                                                                  |
|-------------|--------------------------------------------------------------------------|
| `People`    | Имя, Фамилия, Должность, Компания, Ссылка на профиль, Источник, Дата сбора |
| `Companies` | Название, Сайт, Город, Размер, Ссылка на страницу, Источник, Дата сбора    |

## Какие ссылки понимает

| Ссылка | Что собирается |
|---|---|
| `https://jobs.dou.ua/companies/<компания>/` (и любые её подстраницы) | компания + люди со страницы «Офіси» |
| `https://jobs.dou.ua/companies/?city=…&category=…` (каталог) | первые `DOU_LIST_LIMIT` компаний каталога, по каждой: компания + люди |
| `https://dou.ua/users/<ник>/` | человек |
| `https://www.linkedin.com/company/<компания>/` | компания (название, сайт, размер, город) |
| `https://www.linkedin.com/company/<компания>/people/` (можно с `?keywords=…`) | компания + люди со вкладки People |
| `https://www.linkedin.com/search/results/people/?…` | люди из результатов поиска (идёт по страницам до лимита) |
| `https://www.linkedin.com/in/<профиль>/` | человек |

Если какое-то поле на странице не найдено, ячейка остаётся пустой. Ошибка на одной ссылке не останавливает
остальные: она пишется в `errors.log` (время, ссылка, причина).

## 1. Установка

Нужен Python 3.10 или новее.

```bash
cd contact-parser
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
cp .env.example .env        # Windows: copy .env.example .env
```

## 2. Первый вход в LinkedIn

Проще всего через интерфейс: запустите `python app.py`, откройте http://localhost:8000 и нажмите
**«Войти»** вверху справа. Или из консоли:

```bash
python main.py --login
```

Откроется окно браузера со страницей входа LinkedIn. Войдите руками (логин, пароль, код, если спросит).
Как только вход выполнен, окно закроется само, а сессия сохранится в папке `browser_profile/`.
Дальше парсер работает уже залогиненным. Пароль нигде не хранится.

Вверху интерфейса всегда видно состояние: зелёная точка «вход выполнен · до ДД.ММ.ГГГГ» или красная
«нужен вход». Если LinkedIn разлогинит, нажмите «Перевойти».

Для dou.ua вход не нужен.

## 3. Подключение Google Sheets

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте проект (или возьмите существующий).
2. **APIs & Services → Library**: включите **Google Sheets API** и **Google Drive API**.
3. **APIs & Services → Credentials → Create credentials → Service account**. Создайте его, роль можно не выдавать.
4. Откройте созданный service account → вкладка **Keys → Add key → Create new key → JSON**.
   Скачанный файл положите в папку проекта как `service_account.json`.
5. Создайте Google Таблицу. Нажмите **«Поделиться»** и дайте доступ **«Редактор»** адресу из поля
   `client_email` в JSON-ключе (вида `…@….iam.gserviceaccount.com`).
6. Скопируйте ID таблицы из её адреса: `https://docs.google.com/spreadsheets/d/`**`<ID>`**`/edit`.
7. Впишите в `.env`:

   ```
   SHEET_ID=<ID>
   GOOGLE_KEY_PATH=service_account.json
   LIMIT=100
   ```

Листы `People` и `Companies` с заголовками парсер создаст сам.

> Если `SHEET_ID` оставить пустым, результат пишется в `output/people.csv` и `output/companies.csv`.
> Удобно, чтобы проверить работу до настройки таблицы.

## 4. Запуск из консоли

Впишите ссылки в `input.txt`, по одной в строке (строки с `#` пропускаются), и запустите:

```bash
python main.py input.txt
python main.py input.txt --limit 30    # свой лимит профилей LinkedIn на этот запуск
```

В консоли видно, какая ссылка обрабатывается и сколько записей добавлено. `Ctrl+C` останавливает запуск.

## 5. Запуск через интерфейс

```bash
python app.py
```

Откройте в браузере http://localhost:8000.

- **Ссылки.** Вставьте ссылки по одной в строке. Тип каждой определяется сразу: DOU или LinkedIn,
  компания, люди, поиск, профиль. Нераспознанные строки подсвечиваются красным ещё до запуска.
- **Запустить / Остановить.** «Остановить» завершает запуск после текущей страницы. Всё, что уже собрано,
  остаётся в таблице.
- **Ход запуска.** У каждой ссылки свой статус: в очереди, идёт, готово (+N человек), ошибка с причиной.
  Полоса прогресса состоит из сегментов, по одному на ссылку.
- **Телеметрия.** Сколько прошло и сколько примерно осталось. Таймер текущей паузы между страницами.
  Добавлено людей и компаний, число ошибок, шкала лимита LinkedIn (например, 37 / 100).
- **Контакты.** Найденные люди и компании появляются в таблице прямо во время сбора. Записи, которые уже
  были в Google Таблице, помечены «дубль» и повторно не добавляются.
- **Лог** — каждое действие. **История** — итоги прошлых запусков (хранятся в `runs.json`).
- **Звук и уведомление** по окончании и при остановке из-за LinkedIn. При первом запуске браузер спросит
  разрешение на уведомления. Звук выключается кнопкой с динамиком.
- **«Открыть Google Таблицу»** ведёт прямо в таблицу из `.env`.

Статус обновляется каждые 2 секунды. Одновременно может идти только один запуск. Лимиты и паузы те же,
что в консоли. Консоль и интерфейс используют один профиль браузера, поэтому не запускайте их одновременно.

## Защита аккаунта LinkedIn

- Между страницами случайная пауза 3–8 секунд (`PAUSE_MIN` / `PAUSE_MAX` в `.env`). Пауза действует и для dou.ua.
- Лимит профилей LinkedIn за запуск: `LIMIT` (по умолчанию 100). Когда он исчерпан, остальные
  ссылки LinkedIn получают ошибку «достигнут лимит», а ссылки dou.ua обрабатываются дальше.
- Если LinkedIn показывает капчу, checkpoint, «security check», предупреждение о необычной активности,
  лимит поиска (commercial use limit) или страницу входа, **весь запуск останавливается** и показывается понятное
  сообщение. Пройдите проверку вручную в обычном браузере и сделайте перерыв перед новым запуском.
- Браузер по умолчанию запускается с окном (`HEADLESS=false`). Это похоже на обычную работу пользователя.
- Разумный режим работы: не больше 100–150 профилей в день с одного аккаунта.

Учтите, что пользовательское соглашение LinkedIn запрещает автоматический сбор данных. Риск ограничения
аккаунта есть всегда, лимиты его только снижают. Собранные данные — персональные: используйте их
только для деловых контактов и храните таблицу с ограниченным доступом.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `Вы не залогинены в LinkedIn` или `HTTP 403 … проверьте вход` | Кнопка «Войти» в интерфейсе или `python main.py --login` |
| `Таблица не найдена или нет доступа` | Дайте доступ «Редактор» адресу `client_email` из JSON-ключа |
| `Не найден ключ service account` | Проверьте `GOOGLE_KEY_PATH` в `.env` |
| `сайт ответил HTTP 403, жду …` (dou.ua) | dou.ua временно ограничил частоту запросов. Парсер подождёт и повторит один раз. Если повторяется, увеличьте `PAUSE_MIN`/`PAUSE_MAX` |
| `на вкладке People не найдено людей` | Компания скрывает сотрудников или видны только «LinkedIn Member» (вне вашей сети) |
| `BrowserType.launch_persistent_context: … ProcessSingleton` | Профиль браузера занят: закройте другой запуск (`main.py` или `app.py`) |

LinkedIn регулярно меняет разметку. Если какое-то поле стало приходить пустым, селекторы находятся
в `linkedin.py`, в функциях `parse_company`, `parse_people_cards` и `parse_profile`.

## Структура

```
main.py               запуск из консоли (+ --login)
app.py                локальный интерфейс (Flask)
templates/index.html  страница интерфейса
runner.py             общий движок: обход ссылок, паузы, лимиты, остановка, errors.log
dou.py                парсер dou.ua
linkedin.py           парсер LinkedIn
sheets.py             запись в Google Sheets (или CSV) без дублей
common.py             настройки из .env, модели записей, утилиты
tests/                офлайн-тесты разбора: python -m unittest discover tests
.env.example          SHEET_ID, GOOGLE_KEY_PATH, LIMIT и необязательные настройки
```
